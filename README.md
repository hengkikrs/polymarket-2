# Poly V3 Bot

A trading bot built for Polymarket's BTC Up/Down markets.

## Features
- Automated trading based on market context and volatility (Gamma)
- Real-time dashboard to monitor positions, PnL, orderbooks, and BTC Delta
- Multiple layered execution strategies
- Extensive risk management settings

## Dashboard
The dashboard provides a live UI to track the `END_WINDOW` runtime. It visualizes PnL per trade, cumulative PnL, recent trades, and current decision states.

## Setup
Refer to `requirements.txt` for Python dependencies.
Run `run.bat` or `run_dev.bat` to start the bot.
